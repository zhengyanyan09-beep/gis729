# 空中生命线

基于 GIS 的城市低空医疗急送任务规划与仿真调度平台。演示范围为上海市长宁区，采用 Vue 3、Mapbox GL、Turf.js 和 ECharts 开发。

## 运行

```bash
npm install
npm run dev
```

## 推荐演示流程

1. 从“低空总览”查看医院分布、起降点覆盖范围和低空/地面时效对比。
2. 进入“新建急送任务”，选择第四五五医院，填写 A 型红细胞、2kg、30分钟、需要冷链。
3. 提交后进入 GIS 任务规划，系统按载重、电量、冷链和空闲状态筛选无人机。
4. 对比路线 A 和路线 B。路线 A 与模拟管制区相交，路线 B 绕行并建立120米安全走廊。
5. 确认方案，播放无人机飞行仿真，抵达后完成医院签收。
6. 在任务中心查看归档记录，或导出 GIS 分析报告。

## 数据边界

医院与上海市血液中心名称、地址和位置为公开信息整理。无人机、起降点、任务、服务半径和空域采用项目仿真数据，不代表已投入运行的真实低空航路。

数据参考：

- 上海市长宁区医疗机构公开信息：https://www.shcn.gov.cn/col7770/20250429/1285773.html
- 上海市血液中心官网：https://www.sbc.org.cn/portal/list/index/id/1.html?fuid=0

## GIS核心

项目并非普通管理系统加地图，而是将空间距离、缓冲区覆盖、空间相交、路线绕障、安全走廊和路线评价直接用于调度决策。所有计算在浏览器中完成，不依赖后端和真实无人机接口。
